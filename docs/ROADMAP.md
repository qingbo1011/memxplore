# Roadmap

## v0.1.0 - token-level lifecycle reference (released 2026-08-08)

- Repository charter, architecture decisions, research catalog, bilingual entrypoints, and CI.
- Domain/application contracts and a CGO-free SQLite store with storage safety validation.
- Provider-neutral generator and embedding ports, versioned Strategy Packages, and durable jobs.
- FTS5/BM25 lexical, exact-cosine semantic, and RRF hybrid retrieval.
- Factual, experiential, and working-memory lifecycle references, each with generator-free and generator-assisted strategies.
- REST/OpenAPI, selected MCP tools, CLI, Go SDK, scoped API tokens, and AgentEvent v1.
- Deterministic evaluation, replayable traces, OpenTelemetry, LongMemEval v1, and LongMemEval-V2 Small smoke support.
- Codex and bounded local Ollama E2E evidence, migration/security/cross-platform gates, and the public `v0.1.0` release.

## Later research tracks

The following are deliberate roadmap items, not hidden v0.1 stretch goals:

- Planar graph/tree memory and hierarchical memory.
- A Python lab for latent and parametric memory experiments.
- Complete multimodal formation and retrieval beyond typed artifact references.
- Multi-agent shared-memory policy research.
- LongMemEval-V2 full evaluation and LoCoMo compatibility.
- High availability, enterprise IAM, managed deployments, and an editable web interface.
- Hermes and OpenClaw AgentEvent adapters.

Roadmap entries are not availability promises. Each future release will define its own evidence-backed scope.
