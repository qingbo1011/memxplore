# MemXplore v0.1.0

MemXplore v0.1.0 is the first public release of the executable agent-memory research panorama. It delivers the complete token-level lifecycle for factual, experiential, and working memory through one CGO-free Go binary.

## Highlights

- Formation, governed evolution, retrieval, archive, forget, purge, and traceable consolidation for all three v0.1.0 memory functions.
- Structured recall bundles over lexical, semantic, and hybrid retrieval, including citations, trust, conflicts, token budgets, and score explanations.
- CLI, REST/OpenAPI, selected MCP tools, stdio MCP, Go SDK, and AgentEvent v1 mapped to shared application contracts.
- Durable jobs, scoped hashed tokens, portable subject migration, verified SQLite backup/restore, and explicit security release gates.
- Immutable benchmark reports, local Codex + Ollama E2E evidence, and reproducible Go 1.26 release archives.

## Evaluation evidence

| Run | Scope | Result |
| --- | --- | --- |
| Internal lifecycle | Three deterministic paired scenarios | 9/9 lifecycle checks; lexical Recall@5 and MRR 1.0 |
| LongMemEval v1 | All 500 cleaned questions, session-level lexical retrieval | Hit@5 0.9702; Recall@5 0.9197; MRR 0.9244; 0 failures |
| LongMemEval-V2 Small | 10-question adapter smoke | 10/10 schema and materialization checks |
| Local answer comparison | Two questions, same local model with and without memory | Exact accuracy 0/2 without memory; 1/2 with lexical memory; 0 failures |

The LongMemEval v1 values are session-retrieval metrics, not the official model-judged question-answering score. The V2 result is an adapter smoke, not a memory-quality result. Two local answer cases validate the bounded E2E path but cannot estimate answer quality.

The release E2E ran on Darwin arm64 with Go 1.26.4 and the preinstalled local Ollama models below. Thinking was disabled for native generation. MemXplore did not download a model or call a cloud model.

## Known limits

- MemXplore is a research reference and experiment workbench, not a production memory service.
- Graph, hierarchical, latent/parametric, complete multimodal, high-availability, enterprise IAM, and editable web UI work remains on the roadmap.
- Tier 2 assets have cross-build evidence only.
- Release evidence excludes upstream benchmark datasets, model weights, credentials, and restricted data.
